Metadata blocks

Después de cargar al menos un .tsv, el script ofrece actualizar Solr. Es necesario para que los campos nuevos se indexen y se puedan buscar. Si se omite la actualización, el bloque queda cargado en la base pero no se puede usar en búsquedas.Depois de carregar pelo menos um .tsv, o script oferece atualizar o Solr. Isso é necessário para que os novos campos sejam indexados e possam ser pesquisados. Se a atualização for ignorada, o bloco fica carregado no banco, mas não pode ser usado em buscas.

Idiomas: languages.zipIdiomas: languages.zip

El script no genera languages/languages.zip: solo lo sube si ya existe. Para crearlo, usa los archivos .properties del repo dataverse-language-packs de LA Referencia, en la raíz del zip (sin subcarpetas). Los archivos deben llamarse con los códigos en, es y pt.O script não gera languages/languages.zip: ele só o envia se o arquivo já existir. Para criá-lo, use os arquivos .properties do repositório dataverse-language-packs da LA Referencia, na raiz do zip (sem subpastas). Os arquivos devem se chamar com os códigos en, es e pt.

Reiniciar el contenedor dataverse después de subir el zip es obligatorio.Reiniciar o contêiner dataverse depois de enviar o zip é obrigatório.

Método manualMétodo manual

Útil para aplicar solo algunos ajustes o depurar fallos. Se ejecuta dentro del contenedor:Útil para aplicar só alguns ajustes ou depurar falhas. Execute dentro do contêiner:

docker exec -it dataverse bash
UNBLOCK_KEY=<tu_BLOCKED_API_KEY>
BASE_URL=http://localhost:8080
curl -H "X-Dataverse-unblock-key:$UNBLOCK_KEY" -X PUT \
  -d '/var/www/dataverse/branding/custom-header.html' \
  "$BASE_URL/api/admin/settings/:HeaderCustomizationFile"
# Igual para :FooterCustomizationFile, :StyleCustomizationFile y :HomePageCustomizationFile
curl -H "X-Dataverse-unblock-key:$UNBLOCK_KEY" -X PUT \
  -d '[{"locale":"en","title":"English"},{"locale":"es","title":"Spanish"},{"locale":"pt","title":"Portuguese"}]' \
  "$BASE_URL/api/admin/settings/:Languages"

El UNBLOCK_KEY es el valor de BLOCKED_API_KEY en el .env.O UNBLOCK_KEY é o valor de BLOCKED_API_KEY no .env.

El idioma queda solo en español. Aunque se configure :Languages, el idioma por defecto sigue siendo el español. El script locale.sh lo corrige antes de que arranque la interfaz. O idioma fica só em espanhol. Mesmo com :Languages configurado, o idioma padrão continua sendo o espanhol. O script locale.sh corrige isso antes de a interface subir.
